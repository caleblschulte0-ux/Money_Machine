# App Privacy — draft answers (from docs/PRIVACY.md)

Not legal advice. Every row below cites the section of docs/PRIVACY.md that
supports it; if the code changes, that document changes first.

## Data collected

| Category | Data type | Linked to identity? | Used for tracking? | Purpose | Source |
|---|---|---|---|---|---|
| User Content | Other user content (transcribed speech, facts the child states) | No — no account; a random install id only | No | App functionality | §1, §3 |
| Identifiers | Device ID (random install identifier generated by the app, not IDFA/IDFV) | No | No | App functionality (rate limiting) | §1 |

Not collected: contacts, location, photos, purchases, financial info,
health, browsing/search history, diagnostics, crash data, advertising data.
There is no advertising SDK, analytics SDK or crash reporter (§1).

## Answers to the questionnaire

- Do you or your third-party partners collect data from this app? **Yes** (the rows above).
- Is any data used to track users across apps/websites? **No.**
- Audio data: **not collected** — the microphone is transcribed on-device and the audio is never written to disk or sent (§2).
