# Money_Machine

Product ventures monorepo. Each product lives in its own top-level directory.

| Directory | Product | Status |
|---|---|---|
| [`barkly/`](barkly/) | **Barkly** — AI-powered virtual dog. Mobile app first, physical interactive toy later. | MVP in development |

Each product directory is self-contained: its own README, docs, and app code.

Barkly also carries a ready-to-share handoff package at
[`barkly/handoff/`](barkly/handoff/) — brief, code snapshot, concept sheet,
screenshots, and a zip you can hand to a collaborator or another AI.
