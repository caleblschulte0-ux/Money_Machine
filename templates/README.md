# Templates

Reusable artefacts for venture operations — proposal outlines, onboarding
checklists, report skeletons.

**Currently empty.** Templates should be extracted from work that has actually
been delivered, not invented in advance. The automation agency will produce the
first ones after its first audits.

For scaffolding a new venture module, use `pnpm venture:scaffold` instead,
which generates the package and the nine required documents as prompts rather
than filler.
